Política de privacidad

Última actualización: 11 de noviembre de 2026.

1. Descripción de la aplicación

Rclone ThinkPad L14 es una integración de uso personal que utiliza Rclone para acceder a Google Drive desde un equipo con EndeavourOS Linux y KDE Plasma.

No es un servicio comercial ni una plataforma de almacenamiento independiente.

2. Información a la que se accede

Con autorización del usuario, la integración puede acceder a archivos, carpetas y metadatos almacenados en Google Drive.

El permiso de acceso completo permite consultar, descargar, crear, modificar, organizar y eliminar archivos de acuerdo con las acciones realizadas por el usuario o las tareas que este configure.

3. Finalidad del uso de datos

La información se utiliza exclusivamente para proporcionar acceso personal a Google Drive, facilitar la administración de archivos y ejecutar las operaciones autorizadas desde el equipo local.

No se utiliza para publicidad, elaboración de perfiles comerciales ni comercialización de datos.

4. Almacenamiento y seguridad

Rclone funciona localmente en el equipo autorizado. Su configuración puede almacenar credenciales y tokens OAuth necesarios para mantener la conexión.

Los archivos pueden almacenarse temporalmente en una caché local para permitir su lectura y escritura. Los datos se intercambian con Google mediante sus API y conexiones seguras.

El sitio web informativo no solicita contraseñas, no recibe tokens OAuth y no almacena archivos de Google Drive.

5. Compartición de información

Esta integración no está diseñada para enviar información personal a servidores propios ni compartirla con anunciantes o intermediarios.

El funcionamiento requiere comunicarse con los servicios de Google. Rclone puede interactuar además con los proveedores que el usuario configure expresamente.

6. Conservación y eliminación

Las credenciales y los archivos temporales permanecen en el equipo mientras sean necesarios para la configuración y el funcionamiento de Rclone, o hasta que el usuario los elimine.

El usuario puede eliminar la configuración local, limpiar la caché y revocar la autorización desde la configuración de seguridad de su cuenta de Google.

7. Control del usuario

El propietario mantiene el control de sus archivos y de los permisos concedidos a la integración. Puede suspender su funcionamiento, modificar su configuración o revocar el acceso en cualquier momento.

La revocación puede realizarse desde las conexiones de la cuenta de Google .

8. Uso limitado de los datos

El uso de los datos obtenidos mediante Google Drive API se limita a las funciones de administración de archivos descritas en esta política y debe respetar la Política de Datos de Usuario de los Servicios API de Google, incluidos los requisitos de uso limitado que correspondan.

9. Contacto

Para consultas relacionadas con esta integración, utiliza el correo de asistencia indicado en la pantalla de consentimiento OAuth de Google.
